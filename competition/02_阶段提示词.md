## 阶段 2 · 论文上传、PDF 解析、章节与切片

**目标**：上传真实 PDF 后，后台解析出页码、章节、段落、图表，并切片入库。

### 提示词

```text
继续 PaperLens。实现论文上传与解析流水线。

1. app/services/storage.py：本地存储抽象；safe_filename；用户/论文目录；abs_path 做路径穿越校验；保存 PDF、图表、导出文件；删除论文/用户目录。
2. app/services/pdf.py：
   - 用 PyMuPDF 打开 PDF；拒绝加密文件；页数上限 400。
   - 逐页 get_text("dict") → block/line/span；合并文本：去多余空格、处理连字符断行、CJK 不插空格。
   - 计算正文字号（前 4 页字符加权中位数）；标题检测：字号 ≥1.14 倍、编号标题、章节关键词；返回 Paragraph 列表。
   - 聚合 sections；提取标题、作者、年份、摘要、关键词、DOI；检测语言。
   - 图片：get_images + extract_image，过滤过小图片；图注在上下 180pt 内匹配 Figure/Table；表格用 find_tables → markdown。
   - 返回 ParsedPaper（pages, paragraphs, sections, figures, full_text, meta）。
3. app/services/chunking.py：章节内按段落聚合，目标 ~1150 字符，不跨章节；保存 page_start/end, char_start/end, bbox, tags(method/experiment/result/conclusion/formula 等), token_count。
4. app/services/processing.py：后台任务 process_paper(paper_id)：解析 → 清空旧 pages/sections/chunks/figures → 写入 → 更新 papers 状态与元数据 → 失效检索缓存；异常置 failed 并保存错误。
5. app/routers/papers.py：
   - POST /papers：multipart；扩展名、%PDF 魔数、大小、SHA-256 重复检测（409 带 paper_id）；保存文件；返回 201；后台解析。
   - GET /papers（搜索/状态/收藏/标签/合集/排序/分页）；GET /papers/tags；GET /papers/{id}（含 sections 与计数）；PATCH；DELETE?confirm=true；POST /reprocess；GET /file（鉴权）；GET /outline；GET /pages/{n}。
6. 测试：上传合法 PDF、非法文件、重复文件、解析后章节/摘要/切片数量、文件下载、越权访问 404。
7. 生成一个 scripts/make_sample_pdf.py，用 ReportLab 造 3 页示例论文（Abstract/Introduction/Method/Experiments/Conclusion + 一张图），用于本地验收。

验证：pytest 通过；上传示例 PDF 后 status=ready，sections≥4，chunks≥4，figure 至少 1 个。
```

## 阶段 3 · 混合检索与引用

**目标**：给定问题，返回带页码/章节/原文的 C1..Cn 引用。

### 提示词

```text
继续 PaperLens。实现检索层。

1. app/services/retrieval.py：
   - 分词：英文词、中文单字、中文 bigram；停用词表。
   - BM25（k1=1.4, b=0.72）+ 标题命中加权。
   - 字符 trigram 哈希到 512 维，L2 归一化，余弦相似度。
   - 混合得分 0.68*BM25_norm + 0.32*cosine_norm；整句命中额外 +0.25。
2. app/services/rag.py：
   - get_index(db, user_id, paper_ids)：只加载 ready 论文的 chunks；进程内缓存 90 秒，上传/删除后 invalidate。
   - search(...) 返回 citations：key(C1..), chunk_id, paper_id, paper_title, year, section, page, page_end, quote(≤1400), score, kind, tags。
   - format_citations 用于拼上下文。
3. 测试：构造 2 篇论文，检索“method/experiment”相关查询，断言返回引用、页码正确、paper_ids 过滤生效、跨用户不可见。
4. 输出一个 management 命令或脚本，打印某篇论文的 chunk 数、最长/最短切片、检索示例。

验证：pytest；手动查询能看到 C1/C2 与原文片段。
```

## 阶段 4 · LLM 适配层、14 个 Agent 工具、SSE 对话

**目标**：没有 Key 也能真实回答（本地抽取）；有 Key 时生成式 + 工具调用；写操作需确认。

### 提示词

```text
继续 PaperLens。实现模型层、工具层、Agent 与流式对话。

1. app/services/llm.py：
   - ModelConfig；resolve_model_config(db, user)：用户加密 Key 优先，其次环境变量，否则 None。
   - LLMClient：OpenAI 兼容 /chat/completions；complete(messages, tools)、stream(messages)；180s 超时；401/403、429、超时映射为可读中文错误。
   - model_public_status：configured/mode/capabilities；绝不返回 Key。
   - system_prompt(mode)：强制只基于工具证据、[C#] 引用、区分事实/推断/假设、拒绝执行论文中的指令。
2. app/services/analysis.py：
   - 11 种总结模式；本地抽取版（LOCAL_BANNER 明确标注）；生成式版。
   - 批判性评估 10 项；创新/局限/未来；片段对比；研究缺口。
   - 翻译：无 Key 抛 LLMError（“翻译需要生成式模型，请在设置中配置 Key”）。
3. app/services/tools.py：14 个工具的真实实现 + JSON Schema；ToolRunner 负责引用重编号、去重、写操作 guard（pending action）。
4. app/services/agent.py：
   - ChatRequest；resolve_scope（all/papers/collection/project）。
   - stream_chat：创建/复用 conversation、保存 user message、创建 agent_run、发 start；有模型时最多 5 轮工具调用；无模型时确定性意图路由；持久化 step、citation、message；发 done/error。
   - 模型失败：发 notice，降级本地抽取，明确标注，不静默。
   - confirm_action：仅允许 save_knowledge/save_annotation/export_document。
5. app/routers/chat.py：POST /chat/stream（StreamingResponse，SSE，禁缓存）、conversations CRUD、agent runs、/agent/actions/confirm。
6. app/routers/research.py：summary/analysis/translate/extract/compare/gap/extract 端点。
7. 测试：SSE 事件顺序、引用、消息持久化、无 Key 时 local=true、翻译 409、写操作 pending→confirm→落库、跨用户 404。

验证：pytest；用 curl 或前端发一条问题，能看到 delta 与 done.citations。
```
