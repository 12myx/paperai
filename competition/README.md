# 赛题提示词包 · 使用说明

本目录是给 **华为云码道** 用的提示词与执行手册，配合 PaperLens AI 参赛。

## 文件顺序

| 文件 | 用途 | 给谁看 |
| --- | --- | --- |
| `00_赛题解读与提交清单.md` | 赛题要求、评分映射、提交包结构 | 你 |
| `01_主提示词.md` | 项目总纲：角色、规格、验收标准 | 码道（第一条） |
| `02_阶段提示词.md` | 12 个阶段的逐步提示词 | 码道（按顺序） |
| `03_赛题材料提示词.md` | 说明文档、PPT、视频脚本、证据包、Q&A | 码道 |
| `04_执行手册与证据清单.md` | 手动操作、截图、打包、提交检查 | 你 |
| `05_最短启动提示词.md` | 时间紧时的“一口气”垂直切片 | 码道 |
| `赛题原文.txt` | 从 .doc 抽取的赛题全文 | 参考 |

## 推荐流程

1. 读 `00`，确认提交结构与评分策略。
2. 新建码道工作区，发 `01_主提示词.md`。
3. 按 `02` 阶段 0→11 逐步执行；每阶段截图 + Git commit + 更新 `prompt_log.md`。
4. 用 `03` 生成说明文档、PPT 文案、视频脚本、证据包模板、答辩 Q&A。
5. 用 `04` 做真实截图、录视频、打包、提交。
6. 提交前用 `03` 的“评分表自检”提示词让码道挑毛病。

## 时间紧的最低路径（1 天）

`05` 最短启动 → `02` 阶段 8（阅读器）→ 阶段 10（测试）→ 阶段 11（部署）→ `03` 材料 → 录视频 → 打包。

## 重要提醒

- 赛题要求**真实**的码道使用记录；请实际在码道里开发，不要伪造截图。
- 现有 PaperLens 源码可作为“参考实现”，让码道审计后按模块重建；见 `04` 的“参考实现审计提示词”。
- 没有模型 Key 时，演示“本地抽取模式”也是产品亮点；不要伪造生成式结果。
- 提交包内不要放 `.env`、API Key、个人手机号、未授权论文。
