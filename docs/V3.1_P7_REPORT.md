## 4. 关键设计

1. **自动标签不覆盖手动标签**；来源标签与关键词分开显示。
2. **重复检测默认阻断**，显式 force/确认才允许；Agent 也走确认动作。
3. **版本 append-only**；回滚生成新版本，不删除历史。
4. **聚类是标签聚类**，不冒充语义主题模型。
5. **检索复用 HybridIndex**，与论文检索一致、离线可复现。

## 6. 限制

1. 无 embedding / 语义聚类。
2. 自动标签中文词表有限。
3. 重复阈值可能产生误判。
4. 合并删除来源条目，来源版本不再保留。
5. 历史重复需要人工合并。
6. 旧条目的 meta/version 在首次列表加载时补建；新路径已统一创建。
