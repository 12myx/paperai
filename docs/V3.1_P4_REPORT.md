# V3.1 · P4 多论文升级实施报告

> 日期：2026-11-04
> 范围：PaperFacet、证据矩阵、观点冲突、方法演化/时间线、实验条件、缺口跨论文验证
> 原则：不重写既有 compare/gap；在 Evidence System 之上增加结构化层

---

## 1. 交付

### 数据

| 表 | 作用 |
| --- | --- |
| `paper_facets` | 每篇论文的六维研究画像 + 证据 |
| `research_insights` | 矩阵 / 冲突 / 演化 / 缺口验证的结构化结果与缓存 |

### 服务

`backend/app/services/multipaper.py`

- `ensure_facets`：本地抽取或模型提取，按用户+论文 upsert；
- `_local_field`：按章节 tag + 正则 + 句子打分选择；
- `_model_facets`：严格 JSON，quote 仍本地核验，失败回退；
- `build_matrix`：行 = 论文，列 = 六维，保存 insight；
- `build_conflicts`：模型结构化冲突 + 可比性；本地只并列；
- `build_evolution`：真实年份时间线 + 有证据的关系；
- `validate_gap`：检索相关证据覆盖，不冒充语义支持。

### API

新增 6 条（API 总数 89）：

- `POST /research/matrix`
- `POST /research/conflicts`
- `POST /research/evolution`
- `POST /research/gap/validate`
- `GET /research/insights`
- `GET /research/insights/{id}`

### 前端

- 多论文页新增 3 个 Tab：证据矩阵 / 观点冲突 / 方法演化；
- 矩阵：筛选、搜索、核验过滤、复制 Markdown、单元格回原文；
- 冲突：条件对照、可比性、冲突卡片、本地并列画像；
- 演化：年份时间线、关系状态、证据；
- 缺口验证：输入缺口 → 覆盖论文数 + 证据。

## 5. 限制与风险

1. 本地 Facet 是规则抽取，字段可能不精确；模型模式下 quote 仍核验。
2. 冲突检测与关系推断的语义能力依赖模型；本地模式不冒充。
3. 数据集/指标是文本级比较，不做实体对齐。
4. 只分析资料库，不接入外部学术数据。
5. 矩阵列较多，移动端需横向滚动。
6. 分析结果会随资料库变化过期；P5 需要缓存版本/刷新策略。
