## 6. Reliability findings

- Fixed a real bug: agent_tasks.py referenced LLMError/LLMClient/ModelConfig without imports. Real DeepSeek planning would have failed before this fix.
- Fixed image tool split: read_image and analyze_image were accidentally sharing provider code; read_image now only reads bytes/metadata.
- Duplicate tool calls with identical name+args are blocked.
- Tool errors are returned to the model instead of crashing the run.
- Time and tool budgets are enforced.

## 7. Not tested

- Real-model 20-way concurrency.
- PostgreSQL multi-process claim.
- Docker build/run.
- Long-document token overflow at production scale.
- Network interruption/SSE reconnect.
- Real model prompt injection.
- Real vision provider.
