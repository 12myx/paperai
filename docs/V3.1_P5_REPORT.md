## 4. 关键设计决策

1. **先 Scope 后分析**：所有报告必须绑定 scope，避免“把项目结论说成资料库结论”。
2. **本地可解释优先**：没有 Key 时，趋势/连接/机会仍可用，但明确不是生成式结论。
3. **Opportunity 必须来自局限**：不从“方法很新”之类的主观判断生成机会。
4. **连接边必须有来源**：没有 basis 的边不显示。
5. **趋势不做主题聚类**：词频不是主题；避免用“热点”包装小样本。
6. **缓存按论文集合校验**：论文集合变化则缓存失效；手动 force 可重建。

## 6. 限制

1. 不接外部数据源，不能输出全球领域结论。
2. 趋势样本小，年份缺失会显著影响解释。
3. 研究机会不保证创新性/可发表。
4. 生成式模式尚未用真实 Key 做端到端验收。
5. 连接图只反映已记录的 facet/knowledge 关系。
6. >60 篇资料库会截断；需要增量分析。
