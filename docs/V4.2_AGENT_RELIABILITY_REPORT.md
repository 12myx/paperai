## 2. Code fixes

- agent_tasks.py used LLMClient/LLMError/ModelConfig without imports; fixed. This was a real blocker for model-generated plans.
- Loop budgets/timeouts/duplicate protection added.
- Tool registry rejects names outside TOOL_NAMES.
- Tool failures become tool error messages.
- read_image/analyze_image separation fixed after a reconstruction defect found in testing.

## 3. Action reliability

- Persistent ActionRequest table.
- Atomic pending -> executing claim.
- Signed user/tool/args/expiry token.
- Replay/foreign/tamper/expiry rejection.
- Restart persistence verified.
- Cleanup and stale executing reconciliation.
- At-most-once claim, not exactly-once external side effects.

## 4. Resource control

- auto_retrieval flag honored by resolver, tools and local pipeline.
- exclude_ids honored by papers, knowledge, images, artifacts, projects and tools.
- Multi-resource picker with exclude mode.
- Resource usage has a durable resource_usage ledger, /api/agent/runs/{run_id}/resources and a UI panel. Included/read/referenced are visible; comprehensive retrieved coverage is still partial.
