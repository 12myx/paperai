# V4.2 图表库文件式打包

> 旧问题：图表页把所有论文的图和表直接铺成图片网格，条目多时非常拥挤、视觉疲惫。

## 1. 默认视图

图表页默认显示 **论文资料包**，不直接显示图片：

~~~text
论文资料包
Grounded Retrieval Augmentation for Scientific Reading
图 1 · 表 0 · 快照 0 · 待确认 0
~~~

每张卡对应一篇论文，按当前图层显示数量。

## 2. 资料包详情

点击资料包打开紧凑条目列表：

- 类型（图/表/快照/待确认）
- 图注或表格说明
- 页码
- 是否待确认 / 已存视觉记录

列表不铺大图。点击条目才打开原来的图表详情：

- 图片/表格预览
- 质量分
- AI 图表解释
- 注释
- 保存视觉记录
- 这不是图表
- 打开原文页面
- 在 Chat 中提问

## 3. 保持不变

- 精选图表 / 表格 / 页面快照 / 待确认 / 视觉记录 tabs
- 搜索图注或论文
- 图表详情所有操作
- 待确认与扫描页提示
