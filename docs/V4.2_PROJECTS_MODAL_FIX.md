# V4.2 研究项目：创建输入与添加论文修复

## 1. 问题

- 新建项目时项目名称输入异常，最终只留下一个字符（截图中的“1”）
- 打开“添加论文”后一直加载，并反复提示“无法加载论文列表”

## 2. 根因

### 2.1 模态框每次输入都抢焦点

`Modal` 的 effect 依赖：

~~~tsx
useEffect(() => { ... panel.current?.focus(); }, [open, onClose]);
~~~

`onClose` 是父组件内联箭头函数，父组件每次输入 re-render 都会生成新引用，effect 重新执行并把焦点强制移回 modal panel。结果：

- 输入第一个字符
- 组件 re-render
- 焦点被抢走
- 后续字符没有进入输入框

### 2.2 PaperPicker effect 无限重跑

`PaperPicker` 的默认参数：

~~~tsx
initialIds = []
~~~

每次父组件渲染都会创建新的空数组，而 effect 依赖 `initialIds`：

~~~tsx
useEffect(() => { setLoading(true); Promise.all([...]) }, [open, initialIds, toast]);
~~~

打开 picker 后：

- effect 加载
- setLoading / setPapers 触发 re-render
- 新数组引用让 effect 再次执行
- 反复请求论文列表
- 触发限流后显示“无法加载论文列表”

## 3. 修复

### Modal

- 用 `closeRef` 保存最新 `onClose`
- focus/键盘 effect 只依赖 `open`
- 不再因输入而重复 focus

### PaperPicker

- 用 `initialIds.join("|")` 作为稳定依赖 key
- 同一组初始论文只加载一次
- loading 状态可正常结束
