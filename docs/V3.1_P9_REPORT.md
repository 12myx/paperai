## 4. 限制

1. 队列是单进程，不是 Celery/Redis；多实例不共享。
2. 重启恢复依赖 DB 状态；执行中的线程不会被优雅中断。
3. 限流是进程内，多进程不共享。
4. Postgres 未实机验证。
5. 模型 5xx/429 重试没有真实故障注入。
6. 备份是手动 CLI，不是定时任务。
7. 5k index 构建 10s，必须依赖缓存。
