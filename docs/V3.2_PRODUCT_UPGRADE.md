### A5 Research Intelligence

- **缓存可失效**：report data 增加 `_source_signature`，由论文 updated_at、
  title、chunk_count、facets updated_at 和 fields 计算；论文或 facet 变化后
  不再返回旧报告。
- **可比性修复**：`未提及` 不再被归一化成相同数据集/指标；缺数据不判可比。
- **冲突证据约束**：模型返回 `comparable=false` 的冲突不再展示。
- **演化证据约束**：没有 evidence_keys 或 paper_id 不在当前范围的 relation
  不再展示。
- **范围上限透明**：全部资料库超过 120 篇时，标签明确“最近 120 篇”，
  scope 标记 `limited=true`，UI 显示“已达单次分析上限”。

### A6 Agent 编排

- **启动恢复**：服务重启后，遗留 `running/paused` 任务标记 failed，并同步
  AgentRun，避免任务中心永久“运行中”。
- **原子领取**：`POST /agent/tasks/{id}/execute` 用条件 UPDATE 领取 queued
  任务，防止两个客户端同时执行同一任务。
- **模型辅助规划**：有生成式模型时，模型只接收目标 + 论文标题，输出 2–5 个
  步骤；工具名必须属于真实工具带，失败或非法 JSON 回退确定性计划。
  `plan_source` 记录 `model/local`。
- **工具范围约束**：`ToolRunner` 的 read/summarize/compare/retrieve 等
  不再允许访问本次选择范围外的论文。

## 3. 未完成 / 边界

- **没有新增 Alembic 迁移**：当前升级没有改表结构，但后续 schema 变更仍需迁移。
- **没有 Docker/Railway/PostgreSQL 实机验证**。
- **没有真实 DeepSeek Key 验证模型辅助规划与生成式输出**；本地模式回退已测。
- **侧栏可折叠但 Reader AI 面板仍只能开关，不能拖拽宽度**。
- **没有统一通知中心/上下文压缩**；仍使用 Toast 与历史会话。
- **没有外部学术数据源**；趋势和全景仍严格限定资料库。
- **知识库仍未进入普通 Chat 检索**；只参与 Connections 图谱。
- **方法演化/冲突的模型输出真实性依赖模型质量；服务端已做证据/可比性过滤**。
