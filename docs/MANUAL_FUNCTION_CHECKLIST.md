## 1. AI 研究助手（Chat）

- [ ] 研究范围可选择“全部资料库”。
- [ ] 研究范围可选择项目。

- [ ] 可选择图片/图表。
- [ ] 可选择学术成果。
- [ ] 可选择“排除资料”，排除后请求体包含 exclude_ids。

- [ ] 显式资源数量、排除数量在输入区正确显示。
- [ ] 选择资源后，回答引用能跳转到对应知识/图片/成果。

### 1.2 对话与引用

- [ ] 模式切换：快速问答 / 深度阅读 / 多论文研究 / 批判性分析 / 研究探索。
- [ ] 输入普通问题，回答流式输出。
- [ ] 回答带 [C#] 引用。
- [ ] 点击引用能打开阅读器对应页码/原文。
- [ ] “证据视图”可打开并显示引用证据。
- [ ] 回答可复制。
- [ ] 回答可“保存到知识库”。
- [ ] 保存后知识库出现对应条目。
- [ ] 资源使用面板显示进入上下文/工具读取/回答引用。
- [ ] 本地模式明确显示“本地抽取”，不伪装生成式。
- [ ] 空资料库时提示上传论文，而不是编造回答。
- [ ] 生成中可停止生成。
- [ ] 后端错误显示可操作提示，不显示空回答。

### 1.3 Agent 计划/工具

- [ ] 复杂问题触发“任务计划”预览。
- [ ] 计划显示步骤与工具，不自动写入。
- [ ] 可以编辑计划。
- [ ] “执行计划”后逐步执行并返回结果。
- [ ] 执行过程中可取消任务。
- [ ] 取消后不写入新消息。
- [ ] 任务中心能看到对应任务及状态。
- [ ] 自检（self-check）显示证据覆盖/风险。
- [ ] 写操作（保存知识/批注/导出/成果）需要确认。
- [ ] 重复确认同一动作被拒绝，不重复写入。
- [ ] 工具调用超时/轮数上限有明确提示。

### 1.4 Chat 上传

- [ ] 输入区上传 PDF。
- [ ] 上传后自动加入资料库并进入研究范围。
- [ ] 上传失败显示错误原因。
- [ ] 多文件上传进度、部分失败提示正确。
- [ ] 上传完成后 Chat 范围刷新。

## 13. Agent 工具能力

以下 27 个工具已注册，可在 Chat/Agent 中按需触发：

| 类别 | 工具 |
|---|---|
| 论文 | search_papers, read_paper, retrieve_chunks, summarize_paper, translate_content, compare_papers |
| 研究 | research_intelligence, analyze_research_gap, generate_report, search_research_history |
| 知识 | extract_knowledge, save_knowledge, search_knowledge, read_knowledge |
| 批注/图表 | save_annotation, extract_figures, search_images, read_image, analyze_image |
| 项目 | get_project_context, search_project_resources |
| 成果 | list_artifacts, read_artifact, generate_artifact, check_artifact, export_artifact |
| 导出 | export_document |

检查重点：

- [ ] 写工具必须确认。
- [ ] 只读工具不产生写入。
- [ ] 排除资源不会被工具读取。
- [ ] 扫描件不会被当作可生成知识包论文。
- [ ] 图片语义分析不可用时明确说“无法读取像素”，不伪造。
