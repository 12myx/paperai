## 3. 重点修复

- Chat 保存重复知识：409 转为“内容已存在 + 打开已有条目”
- 论文搜索：标题命中优先
- 本地模式提示缩短
- 阅读助手长文默认折叠
- 知识包“保存到知识库”按钮只对当前论文显示
- 研究情报异步模型 500 修复

## 4. 仍需注意

- 知识库搜索宽泛词会返回大量低相关条目（目标排第一）
- 证据库最多 300 条，每篇论文都可能超过 300，筛选后数量不一定变化
- 任务中心 60 条测试任务平铺，无分页/归档
- 纯图片扫描 PDF 会被解析器拒绝（无 OCR）
- 旧失败学术成果需“重新生成”
