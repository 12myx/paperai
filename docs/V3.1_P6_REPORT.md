## 4. 关键设计

1. **计划不是模型独白**：确定性模板，工具/依赖可见。
2. **暂停是协作式**：状态写库，执行器检查点读取，不 kill 进程。
3. **取消在写库前拦截**：任务状态 + TaskCancelled，避免“取消了还多一条回答”。
4. **自检不冒充事实验证**：只检查引用覆盖、失败步骤与明显风险。
5. **任务中心独立于对话**：历史、重跑、证据都可查。

## 6. 限制

1. SSE 断开后没有后台执行器；暂停任务需要留在页面。
2. 没有持久化队列/断点续跑。
3. 计划模板不覆盖所有研究意图。
4. 自检是启发式，不是 claim-level 验证。
5. 取消在工具执行中需等工具返回。
6. 0.4s 启动窗口是为了控制信号，不是任务延迟。
