## 4. 关键设计

1. **先证据，后写作**：模板只组合 facets 与 citations，不凭空写文献。
2. **范围声明是正文的一部分**，不是脚注；质检会检查。
3. **计划/时间表标注建议**，避免被误读为事实。
4. **质检持久化**：每次检查生成报告，可追踪。
5. **本地确定性生成**：不依赖模型 Key，避免不可核验的综述文本。

## 6. 限制

1. 抽取式初稿，不是完整综述。
2. 计划/实验建议不是已验证事实。
3. 质检无 claim-level 语义验证。
4. 重复检测是字符串级。
5. 无外部文献。
6. 无 .pptx 文件，只有大纲。
7. 同步生成，大资料库需队列。
