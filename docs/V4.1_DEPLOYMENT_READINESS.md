## 3. Real-model smoke script

A script is provided at backend/scripts/v41_real_llm_smoke.py.

It requires:

- PAPERLENS_REAL_LLM_AUTHORIZED=1
- a configured model in Settings (API key stored server-side)
- QA_EMAIL / QA_PASSWORD

If not authorized/configured it exits as SKIPPED and makes no paid request.

~~~text
PAPERLENS_REAL_LLM_AUTHORIZED=1 QA_EMAIL=... QA_PASSWORD=... \
  python backend/scripts/v41_real_llm_smoke.py

PAPERLENS_REAL_VISION_AUTHORIZED=1 QA_EMAIL=... QA_PASSWORD=... \
  python backend/scripts/v41_vision_smoke.py
~~~

The vision script fails if the result is only a Mock result or a capability limitation; it does not fake real vision.
