## 1. Overview

V4 extends Chat from paper-only context to five resources:

- Papers
- Personal knowledge
- Research projects
- Image library
- Academic artifacts

Implemented:

1. Unified Context Resolver.
2. Knowledge search/read tools in normal Chat.
3. Project goal/description/notes/resource context.
4. Real image-file reading with size/hash/dimensions.
5. Artifact query, generation, quality check and export tools.
6. Resource-level citations and frontend focus routes.
7. Project association for generated artifacts.
8. Cross-user resource filtering tests.

Limited / not implemented:

- Real visual semantic analysis: the current model client has no vision input.
- Real LLM tool loop: no API key in this environment; no paid call made.
- Full frontend multi-resource picker: backend accepts explicit IDs; frontend supports single-resource handoff buttons from Knowledge/Figures/Artifacts; no one-page multi-select picker yet.

## 3. Architecture

~~~text
Chat request
  -> resolve_scope (papers)
  -> resolve_research_context
       project + items/notes
       knowledge (explicit + project + question)
       images (explicit + project + question)
       artifacts (explicit + project + question)
  -> model context block / local tool routing
  -> ToolRunner
  -> citations + evidence
  -> SSE
~~~

See docs/UNIFIED_RESEARCH_CONTEXT_ARCHITECTURE.md.

## 4. Real tool chain

Knowledge question:

~~~text
search_knowledge
retrieve_chunks
answer
done citations: knowledge + paper chunks
~~~

Project question:

~~~text
get_project_context
retrieve_chunks
summarize_paper
~~~

Image question:

~~~text
search_knowledge
search_images
read_image
analyze_image -> capability limited
retrieve_chunks
extract_figures
~~~

Artifact check:

~~~text
list_artifacts
check_artifact
~~~

Artifact generation:

~~~text
generate_artifact -> pending action
POST /api/agent/actions/confirm
-> AcademicArtifact + ProjectItem
~~~

Tool count: 27.

## 5. Evidence

No new evidence table. Existing Evidence fields are reused:

| Resource | source_type | source_id |
| --- | --- | --- |
| Knowledge | knowledge | knowledge item id |
| Image | image | figure id |
| Artifact | artifact | artifact id |
| Project | project | project id |

harvest_citations creates resource evidence. A resource is not marked verified just because its text looks like a paper fragment; verification still needs a real chunk match. Project evidence is correctly saved with verified=false because project goals are not paper chunks.
