# V3.1 · P3 Evidence System 实施报告

> 日期：2026-11-04
> 范围：统一证据实体、核验、落库、抽屉、证据库页面、自动 harvest、历史回填
> 原则：不重写已有解析/检索/认证模块；不引入 Mock；所有结论基于真实数据与测试

## 1. 交付内容

### 1.1 数据层

新增两张表（`create_all` 自动创建，未改动既有表结构）：

| 表 | 作用 |
| --- | --- |
| `research_analyses` | 持久化 summary / critical / compare / gap / extract 结果，供证据关联与后续 RI 复用 |
| `evidence` | 可验证证据实体：论文、切片、页码、章节、引用、类型、置信度、核验、来源、指纹 |

### 1.2 服务层

`backend/app/services/evidence.py`：

- 6 类证据常量与默认置信度；
- 本地确定性核验 `verify_quote`（精确/片段/句子/前缀/失败）；
- `resolve_chunk`：按 chunk_id 或 paper+page+quote 定位切片；
- `create_evidence`：参数校验、用户隔离、去重、置信度修正；
- `harvest_citations`：从 C1..Cn 自动生成证据；
- `save_analysis`：分析落库 + 证据 harvest；
- `backfill_evidence`：历史消息、批注、知识回填；
- `evidence_stats`：统计；
- `insufficient_for_answer`：明确“证据不足”的回答生成 insufficient 记录。

### 1.3 API

新增 9 条接口（总计 83 条 API 路由）：

- `GET /api/evidence`
- `GET /api/evidence/stats`
- `POST /api/evidence`
- `GET/PATCH/DELETE /api/evidence/{id}`
- `POST /api/evidence/from-annotation/{id}`
- `POST /api/evidence/from-knowledge/{id}`
- `POST /api/evidence/backfill`

### 1.4 自动接入

| 入口 | 行为 |
| --- | --- |
| 对话回答 | 保存 assistant message 后 harvest 引用；无证据但回答明确“证据不足”时写入 insufficient |
| 论文总结 | 生成后写入 `research_analyses`，证据关联 `analysis_id` |
| 批判性分析 | 同上，类型 inferred |
| 多论文对比 | 同上，类型 inferred |
| 研究缺口 | 同上，类型 inferred |
| 自定义提取 | 同上，类型 direct |
| 批注 | 阅读器“加入证据库”调用 from-annotation |
| 知识 | 保存时带 `source_quote` 自动创建证据 |
| 历史数据 | 证据库“回填历史证据” |

### 1.5 前端

- 新增 `EvidenceProvider` 全局证据抽屉；
- 对话回答“证据视图”；
- 阅读器总结/批判/追问“证据”；
- 阅读器批注“加入证据库”；
- 多论文结果“证据”；
- 新增 `/app/evidence` 证据库页面：统计、类型/论文/核验筛选、搜索、回填、删除、打开原文；
- 导航新增“证据库”。

## 4. 已知限制

1. 自动类型只覆盖 direct/shared/inferred/insufficient；hypothesis/external 目前需要手动创建，等 P5/P8 使用。
2. 核验的是“引用是否在原文中”，不是“结论是否被证据支持”；后者属于 P5/P8。
3. 不处理扫描版 PDF（无文本层）。
4. 证据没有版本历史；批注编辑不会自动更新已有证据。
5. 证据库分页为 300 条上限；大规模资料库需要分页/游标（P9）。
6. 旧数据中的 claim 可能是长回答片段；前端只展示 ≤240 字的断言，避免噪音。

## 5. 对 P4 的接口

P4 多论文升级可直接复用：

- `GET /api/evidence?analysis_id=...` 获取某次分析的全部证据；
- `GET /api/evidence?paper_id=&type=&verified=` 构建证据矩阵；
- `research_analyses` 可查询历史对比/缺口结果；
- 冲突检测需新增“可比性”判断，但证据字段已具备数据集/指标扩展位（`meta`）。

**下一步建议：开始 P4（多论文升级）或 P5（Research Intelligence MVP）。**
