# PaperLens AI · 产品说明与验收矩阵

> 版本：0.9.0 · 更新：2026-11-03
> 定位：Your Personal AI Research Companion

## 1. 产品愿景

PaperLens 面向本科生、硕士研究生、博士研究生、高校教师与科研人员，解决三个真实问题：

1. **读不完**：长篇论文与有限注意力之间的矛盾；
2. **信不过**：AI 摘要无法回溯到原文，不能用于正式写作；
3. **留不住**：每次对话从零开始，读完的结论无法沉淀为长期研究资产。

因此产品的核心不是“聊天”，而是：

**解析 → 检索 → 有证据的回答 → 核验 → 批注/知识 → 多论文关联 → 项目沉淀**

## 2. 目标用户与典型任务

| 用户 | 典型任务 | PaperLens 提供的能力 |
| --- | --- | --- |
| 本科生 | 读懂第一篇英文论文 | 通俗总结、术语翻译、逐章解释、原文跳转 |
| 硕士生 | 写综述、找研究方向 | 多论文对比、研究缺口、知识库、项目导出 |
| 博士生 | 批判性阅读、方法复现 | 批判性评估、实验对比、局限分析、片段级对比 |
| 教师/科研人员 | 快速筛选文献、组会材料 | 资料库问答、结构化报告、PDF/DOCX 导出 |

## 3. 设计原则与实际落地

| 原则 | 实现方式 |
| --- | --- |
| AI Agent 优先 | 对话由 15 个真实工具驱动：检索、读取、总结、对比、翻译、提取知识、保存、导出、研究情报等 |
| 所有 AI 内容有依据 | 回答必须携带 [C#] 引用；引用卡片包含论文、页码、章节与原文片段 |
| 原文可追溯 | 切片保存页码、字符偏移与边界框；点击引用跳转到阅读器对应页 |
| 研究成果可保存 | 知识片段、批注、项目条目、对话历史、导出记录全部持久化 |
| 多论文可关联 | 合集、多论文对比、片段对比、知识来源边、知识图谱 |
| 重要操作可撤销 | 批注软删除 + 撤销恢复；删除论文/项目需显式确认 |
| 不用假数据 | 未配置模型时明确显示“本地抽取模式”；翻译/图表解释返回可操作错误，不伪造结果 |

## 6. 已知不足与下一阶段优先级

### P0（最值得做）

1. **接入真实 DeepSeek Key 后完成生成式回归**：翻译、生成式总结、对比、批判性评估的端到端人工验收。
2. **OCR 与扫描版 PDF**：接入 PaddleOCR/Tesseract，覆盖大量扫描文献。
3. **神经向量检索**：当前为 BM25 + 字符 n-gram 混合；可接入 bge-m3 等嵌入模型并做混合重排。
4. **批量导入与 DOI/arXiv 元数据补全**。

### P1

5. 速率限制与审计日志导出。
6. 邮箱验证、密码找回、OAuth 登录。
7. 术语表与全文双语阅读。
8. 团队/课题组的共享资料库（需要权限模型重构）。
9. 后台任务队列（Celery/RQ）替代进程内 BackgroundTasks，支持大 PDF 并发。
10. 自动化 PDF 回归语料库（不同出版社模板）。

### P2

11. 知识自动关联建议、主题聚类、研究趋势时间线。
12. 引用格式导出（BibTeX/APA）。
13. 浏览器扩展 / Zotero 集成。
